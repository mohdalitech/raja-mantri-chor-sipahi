# 👑 Raja Mantri Chor Sipahi

An interactive web-based version of the traditional **Raja Mantri Chor Sipahi** game, built using **Python and Streamlit**.

The application supports 4 players, secret role selection, automatic turn management, multiple rounds, Hindi voice dialogue, dynamic scoring, and winner determination.

## 🎮 Features

* 👥 4-player team creation
* 🃏 Secret chit/role selection
* 👑 Raja
* 🧠 Mantri
* 🕵️ Chor
* ⚔️ Sipahi
* 🔄 Automatic player turn management
* 🔊 Hindi dialogue using browser Text-to-Speech
* 🕵️ Mantri's Chor identification
* 💯 Role-based scoring system
* 🔁 Multi-round gameplay
* 🏆 Automatic winner calculation
* 📊 Final scoreboard
* 🧠 Streamlit Session State for maintaining game state

## 🛠️ Tech Stack

* **Python**
* **Streamlit**
* **HTML**
* **JavaScript**
* **Web Speech API**
* **Streamlit Session State**

## 🎯 How the Game Works

1. Enter the names of the 4 players.
2. Create the team.
3. Select the number of game rounds.
4. Start the game.
5. Each player selects one secret chit.
6. Once all roles are assigned, the Raja–Mantri dialogue is played.
7. The Mantri chooses who they believe is the Chor.
8. Scores are calculated according to the game rules.
9. The next round begins automatically.
10. After all selected rounds are completed, the winner and scoreboard are revealed.

## 💯 Scoring

| Role      | Points                     |
| --------- | -------------------------- |
| 👑 Raja   | 1000                       |
| 🧠 Mantri | 800 if correct             |
| 🕵️ Chor  | 800 if Mantri is incorrect |
| ⚔️ Sipahi | 500                        |

## 🔊 Text-to-Speech

The Raja–Mantri dialogue uses the browser's **Web Speech API**.

Because speech is generated by the user's browser, no separate text-to-speech server or Python package is required.

## 🧠 Key Learning

This project helped me understand how to build a **stateful interactive application with Streamlit**.

The game uses `st.session_state` to maintain:

* Current player turn
* Selected chits
* Player scores
* Current game phase
* Completed rounds
* Game status
* Text-to-Speech status

It was a practical exercise in converting the rules of a traditional game into programmatic **game logic and state transitions**.
